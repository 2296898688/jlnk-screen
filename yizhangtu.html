📋 交互说明

演示专用 · 非系统UI

🗺️ 地图

  • 点击农场圆点 → 飞到该农场，圆点消失只留宗地边界；点缩放按钮或切Tab恢复
  • 点击宗地图斑 → 弹出详情（基本信息 / 宗地 / 权证 / 证书）
  • 悬停圆点或图斑 → 显示 tooltip
  • 滚轮缩放，拖拽平移

🔍 筛选

  • 地图上的图例色块可点击，按确权状态或用地类型过滤图斑，再次点击取消

🛠️ 工具

  • 缩放按钮 + / −，全屏按钮 ⛶
  • 「宗地明细」拉手 → 弹出地块表格

📊 侧栏

  • 左：确权KPI / 面积瀑布图 / 土地利用环形图
  • 右：农场土地类型梯田图 / 确权对比环形图 / 行政区确权进度条

🗺️ 地图

  • 农场圆点 → 点击飞到农场后消失，缩放或切Tab恢复
  • 设备卡片 → 悬停看tooltip，点击弹出详情（实时数据 + 远程控制）
  • 滚轮缩放，拖拽平移

🔍 筛选

  • 点击左侧设备类型卡片筛选设备
  • 按在线 / 离线 / 异常状态过滤

🛠️ 工具

  • 缩放按钮 + / −，全屏按钮 ⛶

📊 侧栏

  • 左：设备总数+告警KPI / 设备类型列表
  • 右：设备信息 / 历史折线图 / 告警列表

🗺️ 地图

  • 点击地块图斑 → 飞到地块，弹出信息卡片
  • 统种地卡片：田间作业档案（收获 + 旋耕→播种→施肥→植保→灌溉→收割时间线）+ 经营统计
  • 承租地卡片：承租基本信息 + 查看合同PDF按钮
  • 农场圆点 → 点击飞到农场后消失，缩放或切Tab恢复
  • 滚轮缩放，拖拽平移

🎬 场景切换

  • 🌱 作物分布：默认模式，地块着色+作物图标，侧栏展示种植数据
  • 🛰 遥感监测：侧栏隐藏全屏，8个指标切换，色标栏+报告面板+透明度滑块
  • 🌤 气象监测：侧栏切为气象图表（可切换近一年/五年），色标栏+数据面板+浮动面板

🔍 筛选

  • 农场切换、年份下拉、搜索地块名称、列表点击飞至
  • 点击统种地/承租地图例 → 互斥筛选，再点恢复全部

🛠️ 工具

  • 缩放按钮 + / −，全屏按钮 ⛶
  • 遥感模式：图层透明度滑块

📊 侧栏（作物分布模式）

  • 左：种植计划+进度表 / 农艺配方列表 / 累计投入饼图
  • 右：承租统种占比 / 整体进度（春播夏管秋收切换）/ 累计投入（农资农机其他切换）
