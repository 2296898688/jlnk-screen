# 农发集团智慧农业综合管控平台

3840×1920（6:3 / 2:1）深色科技风大屏，适配 6m×3m 物理大屏。

## 页面导航

| 页面 | 文件 | 说明 |
|------|------|------|
| 汇总导览页 | `index.html` | 集团概况三栏大屏，底部四入口 |
| 农垦一张图 | `yizhangtu.html` | GIS 驾驶舱（768+2304+768 分栏） |

汇总导览页底部点击 **农垦一张图** → 进入 `yizhangtu.html`；一张图顶栏可 **返回汇总导览**。

## 快速启动

```bash
# 方式一：直接双击 index.html 用浏览器打开

# 方式二：本地 HTTP 服务（推荐）
npx serve .
# 或
python -m http.server 8080
```

浏览器访问后页面会自动等比缩放至当前窗口。

## 目录结构

```
├── index.html          # 汇总导览页
├── yizhangtu.html      # 农垦一张图 GIS 驾驶舱
├── css/style.css       # 汇总页样式
├── css/yizhangtu.css   # 一张图专属布局（768+2304+768）
├── js/data.js          # 子公司与图表数据
├── js/app.js           # 汇总页交互
├── js/yizhangtu-data.js# 一张图模拟数据
└── js/yizhangtu.js     # 一张图地图/图表/筛选/弹窗
```

## 布局规格

| 区域 | 尺寸 | 内容 |
|------|------|------|
| 顶部通栏 | 3840×320 | LOGO、导航、模式切换 |
| 左栏 | 1280×1200 | 集团概况（信息/环形图/时间轴/荣誉） |
| 中栏 | 1280×1200 | 经营核心数据（KPI/TOP5/土地利用） |
| 右栏 | 1280×1200 | 子公司汇总（统计/地图/列表） |
| 底部通栏 | 3840×400 | 四张驾驶舱导览入口卡片 |

## 交互

- 点击右侧地图标注点或子公司列表行 → 弹出详情弹窗
- 弹窗含 5 个标签页：基础信息 / 土地资源 / 经营数据 / 生产数据 / 设备数据
- 底部四入口：农垦一张图（已跳转）、土地资源开发公司一张图、粮食集团一张图、食品公司一张图
